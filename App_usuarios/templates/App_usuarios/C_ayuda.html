Leidy Make Up

Manual de usuario

Sigue estos pasos para crear tu cuenta, consultar servicios y gestionar tus citas.

Iniciar sesión Crear cuenta

1. Registrarte

  1. Abre Crear cuenta.
  2. Escribe tu nombre, correo electrónico y contraseña. El apellido y el teléfono son opcionales.
  3. Selecciona «Crear cuenta». El registro público crea una cuenta de cliente.
  4. Cuando aparezca el aviso de éxito, continúa al inicio de sesión.

2. Iniciar sesión

  1. Abre Iniciar sesión.
  2. Escribe el correo o nombre de usuario y la contraseña de tu cuenta.
  3. Elige «Cliente» o «Estilista» según el tipo de cuenta que ya tienes y envía el formulario.

El registro público no crea cuentas de estilista; estas deben ser asignadas por la administración.

3. Consultar los servicios

  1. Abre el catálogo de servicios para ver los servicios activos.
  2. Revisa el nombre, la categoría, el precio y la duración de cada servicio.

4. Solicitar y agendar una cita

  1. Inicia sesión como cliente y abre «Reservar cita».
  2. Selecciona un servicio, una fecha futura y uno de los horarios disponibles.
  3. Si lo deseas, agrega un mensaje o archivos de referencia y envía la solicitud.
  4. La solicitud queda «Pendiente» hasta que la estilista la confirme o la rechace.

5. Consultar el estado

  1. Inicia sesión y abre «Mis citas».
  2. Consulta allí la fecha, la hora y el estado de cada solicitud: pendiente, confirmada, rechazada, cancelada o finalizada.

6. Cancelar una cita

  1. Abre «Mis citas» y localiza la solicitud o cita.
  2. El botón «Cancelar» está disponible mientras su estado sea «Pendiente» o «Confirmada».
  3. Confirma la acción cuando el navegador lo solicite. Las citas rechazadas, ya canceladas o finalizadas no se pueden cancelar desde esta opción.
La disponibilidad depende de los horarios que muestra el sistema. Si una fecha no tiene horarios disponibles, elige otra fecha. Volver al inicio de sesión
